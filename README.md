# Power BI Portfolio (Next.js)

This project presents a modern, minimal one-page portfolio for a Power BI Developer / Data Analyst using Next.js and Tailwind CSS.

## Run locally

1. Install Node.js (LTS) if not installed.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the dev server:

   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000`

## Sections included

- Cover
- About Me
- Education
- Skills
- Work Experience
- Offered Services
- Projects (Previous Work)
- Achievements
- Testimonials
- Call to Action and Contact Information

## Customize quickly

- Update placeholders in `app/page.tsx` (`[Your Name]`, years, contact links, company names).
- Replace project descriptions with your real dashboard case studies.
- Add links to your LinkedIn and Power BI showcase.
